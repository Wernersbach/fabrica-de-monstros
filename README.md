# Fábrica de Monstros
## Projeto em Linguagem C

---

## 1. Descrição do Projeto
Este repositório contém um programa em linguagem C desenvolvido para a atividade “Fábrica de Monstros”, cujo objetivo é gerar uma descrição estruturada de um monstro a partir de características escolhidas pelo usuário.  
O projeto aplica os conceitos de decomposição, padrões, abstração e construção de algoritmos.

---

## 2. Objetivos
- Implementar um algoritmo em C para criação de monstros.
- Exercitar lógica de programação, seleção (`switch-case`), entrada e saída de dados.
- Representar em software as instruções propostas no material da disciplina.

---

## 3. Funcionalidades
O programa permite escolher:
- Família do monstro
- Tipo do monstro
- Formato da cabeça
- Tipo de olhos
- Tipo de boca
- Cor predominante

O resultado final é um “retrato falado” gerado em texto.
